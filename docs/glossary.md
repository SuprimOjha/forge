# Glossary

- **CLI:** Command-line interface used from a terminal.
- **Command handler:** Code implementing a particular Forge command.
- **CMake:** Build-system generator used to configure and build Forge.
- **Compiler:** Program that translates C++ source into machine code.
- **Dependency graph:** Representation of relationships between project components.
- **Artifact:** Generated file such as a binary, archive, or build output.
- **Workspace:** Project directory being inspected or managed.
- **Smoke test:** Short check verifying basic startup or core behavior.
- **Toolchain:** Compiler and related tools used to build software.
- **Working tree:** Files currently checked out in version control.
