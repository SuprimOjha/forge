# Release checklist

Before preparing a Forge release:

- [ ] Confirm version and release notes agree.
- [ ] Build from a clean checkout with the intended toolchain.
- [ ] Run available tests and basic CLI smoke checks.
- [ ] Verify help and version output.
- [ ] Inspect packaged artifact contents.
- [ ] Document runtime dependencies.
- [ ] Confirm no credentials or private configuration are included.
- [ ] Test installation in a clean environment.
- [ ] Record known limitations and platform-specific issues.

Do not describe an artifact as tested on platforms where it has not actually been tested.
