# Frequently asked questions

## Which C++ standard is required?

The root CMake configuration requires C++20 and disables compiler extensions.

## Which CMake version is required?

The project declares CMake 3.20 as its minimum version.

## How do I see available commands?

Run `forge help` or `forge --help`.

## How do I find options for one command?

Run `forge <command> --help`; options vary by command.

## Does a successful health check guarantee security?

No. Diagnostics are limited to implemented checks and do not replace testing, code review, or security assessment.
