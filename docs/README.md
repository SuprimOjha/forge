# Forge Documentation

Welcome to the Forge documentation. Forge is a native command-line tool for inspecting and maintaining software workspaces. The project is implemented in C++ and configured with CMake.

## Documentation accuracy

Command names and high-level descriptions are based on the current command dispatcher and build configuration. Individual command options may vary by implementation. Run `forge help` and `forge <command> --help` against your built executable before relying on a specific option. Documentation does not imply that every workflow has been tested on every operating system.
