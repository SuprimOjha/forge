# Environment information: env

The `env` command is listed as a way to display detected environment information. It can help establish which tools or settings Forge sees when diagnosing a machine-specific issue.

```sh
forge env
forge env --help
```

Environment output may contain local paths or machine details. Review it before posting logs publicly. When troubleshooting, include the operating system, compiler, CMake version, and relevant output while redacting usernames, tokens, and private directory names when appropriate.
