# Additional utilities

Forge also lists `dashboard`, `cheat`, `parallel`, `run`, `init`, and `version`.

```sh
forge cheat
forge dashboard --help
forge parallel --help
forge run --help
forge init --help
forge version
```

Use `init` only after checking which files it creates or modifies. Parallel execution and run commands can launch processes or trigger project operations; inspect their behavior before using them in an unfamiliar workspace.
