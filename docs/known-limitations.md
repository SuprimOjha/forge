# Known documentation limitations

This documentation describes repository structure and command names, but it is not yet an exhaustive flag-by-flag manual for every command. Some behavior must be verified from implementation and with a built executable.

A command's presence in the dispatcher does not prove every workflow is complete, portable, or tested. Describe platform support only after builds and runtime checks have been performed on the relevant platforms.

Report inaccurate instructions with the command, Forge version, expected and actual behavior, and a minimal reproduction.
