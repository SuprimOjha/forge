# Roadmap ideas

This page records possible improvement areas, not promises that work is already implemented.

Potential priorities:
- Add automated tests for command parsing and core utilities.
- Document exact options for every command from source.
- Add CI builds for supported compiler and OS combinations.
- Improve errors for missing tools and malformed configuration.
- Define contracts for destructive operations and dry-run behavior.
- Add reproducible packaging and installation verification.
- Publish a support matrix based on actual CI results.

Track proposals through issues with clear scope and acceptance criteria.
