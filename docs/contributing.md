# Contributing to Forge

Contributions are welcome when they are focused, reviewable, and supported by evidence.

## Workflow

1. Describe the problem or proposed change.
2. Create a branch for the work.
3. Keep commits focused and use clear imperative messages.
4. Build with the documented toolchain.
5. Test affected commands, including invalid inputs and failures.
6. Update documentation when behavior changes.
7. Submit a pull request with a concise summary and verification details.

Avoid unrelated formatting churn. Do not commit generated binaries, secrets, private configuration, or build directories.
