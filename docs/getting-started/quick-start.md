# Quick start

After building or installing Forge, open a terminal in a project directory and begin with read-oriented commands:

```sh
forge help
forge version
forge project
forge status
forge doctor
```

These commands introduce the command interface, version information, project inspection, repository status, and environment diagnostics. The exact output depends on the current directory and installed tools.

Before using commands that clean files, strip artifacts, run scripts, apply fixes, or create packages, inspect their command help and make sure your work is committed or backed up.
