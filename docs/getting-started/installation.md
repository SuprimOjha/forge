# Installation

## Available paths

Use a prebuilt release if the repository publishes a suitable binary. Otherwise, build Forge from source using CMake and a C++ compiler.

## Verify an installation

Open a terminal and run:

```sh
forge --version
forge --help
```

If the shell cannot find `forge`, check that the executable's directory is on `PATH`, then open a new terminal.

## Safety

Download releases only from the official repository or a source you trust. Review release notes before replacing an existing executable. The exact release assets and installation steps can change between versions; consult the repository's Releases page for current availability.
